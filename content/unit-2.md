## 2.1 פונקציות קדומות ואינטגרל בלתי-מסוים

### הגדרה 2.1 (האינטגרל הבלתי-מסוים ופונקציה קדומה)
* **מקור בספר:** עמ' 109 (PDF עמ' 111; נספח עמ' 256)
תהי $f$ פונקציה ויהי $I$ קטע המוכל בתחום ההגדרה של $f$.
1. פונקציה $F$ נקראת **פונקציה קדומה** של $f$ בקטע $I$, אם $F$ גזירה בכל נקודה ב-$I$ ומתקיים:
   $$F'(x) = f(x) \quad \text{לכל } x \in I$$
2. אוסף כל הפונקציות הקדומות של $f$ בקטע $I$ נקרא **האינטגרל הבלתי-מסוים** של $f$ ב-$I$, ומסומן:
   $$\int f(x)\,dx$$
   דהיינו:
   $$\int f(x)\,dx = \{ F(x) : F'(x) = f(x) \text{ לכל } x \in I \}$$

---

### משפט 2.2 (מבנה אוסף הפונקציות הקדומות)
* **מקור בספר:** עמ' 110 (PDF עמ' 112; נספח עמ' 256)
אוסף כל הפונקציות הקדומות של $f$ בקטע $I$ הוא אוסף כל הפונקציות הנבדלות בקבוע מפונקציה קדומה אחת כלשהי של $f$ בקטע $I$.

**ניסוח שקול:**
אם $F$ היא פונקציה קדומה של $f$ בקטע $I$, אז בקטע $I$ מתקיים:
$$\int f(x)\,dx = \{ F(x) + C : C \in \mathbb{R} \}$$
בכתיב מקובל: $\int f(x)\,dx = F(x) + C$.

---

### דוגמה 2.1
* **מקור בספר:** עמ' 109 (PDF עמ' 111)
מאחר שהנגזרת של $F(x) = \frac{x^3}{3}$ היא $f(x) = x^2$, הרי שכל פונקציה קדומה של $x^2$ היא מהצורה $\frac{x^3}{3} + C$. לכן:
$$\int x^2\,dx = \frac{x^3}{3} + C$$

---

### הגדרה 2.3 (פונקציות אלמנטריות)
* **מקור בספר:** עמ' 112 (PDF עמ' 114; נספח עמ' 256)
הפונקציות האלמנטריות הן הפונקציות הבאות:
1. **הפולינומים:** למשל $P(x) = a_n x^n + \dots + a_1 x + a_0$.
2. **הפונקציות המעריכיות:** פונקציות בעלות הצורה $a^x$ עבור $a > 0$ (ובפרט $e^x$), המוגדרות לכל $x \in \mathbb{R}$.
3. **הפונקציות הלוגריתמיות:** פונקציות מהצורה $\log_a x$ עבור $a > 0, a \ne 1$ (ובפרט $\ln x$), המוגדרות לכל $x > 0$.
4. **הפונקציות הטריגונומטריות:** $\sin x, \cos x$ (מוגדרות לכל $x$), $\tan x$ (מוגדרת לכל $x \ne \frac{\pi}{2} + \pi k$), ו-$\cot x$ (מוגדרת לכל $x \ne \pi k$).
5. **הפונקציות הטריגונומטריות ההפוכות:** $\arcsin x, \arccos x$ בתחום $[-1,1]$, ו-$\arctan x, \operatorname{arccot} x$ המוגדרות לכל $x \in \mathbb{R}$.
6. **פעולות אלגבריות והרכבות:** כל פונקציה שהיא סכום, הפרש, מכפלה, מנה, או הרכבה של מספר סופי של פונקציות אלמנטריות מהסעיפים 1–5 היא בעצמה פונקציה אלמנטרית בתחום שבו היא מוגדרת.

> **הערה מהותית למבחן:** 
> - נגזרת של פונקציה אלמנטרית היא תמיד פונקציה אלמנטרית.
> - לעומת זאת, **לא לכל פונקציה אלמנטרית קיימת פונקציה קדומה שהיא אלמנטרית** (למשל הפונקציות המפורסמות: $e^{-x^2}$, $\frac{\sin x}{x}$, $\frac{1}{\ln x}$, $\frac{e^x}{x}$, $\sin(x^2)$ בעלות פונקציה קדומה שאינה אלמנטרית).

## 2.2 נוסחות אינטגרציה וכללים בסיסיים

### טבלת האינטגרלים המיידיים היסודיים
* **מקור בספר:** עמ' 115 (PDF עמ' 117)
1. $\int x^\alpha\,dx = \frac{x^{\alpha+1}}{\alpha+1} + C \quad (\alpha \ne -1)$
2. $\int \frac{1}{x}\,dx = \ln|x| + C \quad (x \ne 0)$
3. $\int e^x\,dx = e^x + C$
4. $\int a^x\,dx = \frac{a^x}{\ln a} + C \quad (a > 0, a \ne 1)$
5. $\int \sin x\,dx = -\cos x + C$
6. $\int \cos x\,dx = \sin x + C$
7. $\int \frac{dx}{\cos^2 x} = \int (1 + \tan^2 x)\,dx = \tan x + C$
8. $\int \frac{dx}{\sin^2 x} = \int (1 + \cot^2 x)\,dx = -\cot x + C$
9. $\int \frac{dx}{\sqrt{1-x^2}} = \arcsin x + C = -\arccos x + C_1$
10. $\int \frac{dx}{1+x^2} = \arctan x + C = -\operatorname{arccot} x + C_1$
11. $\int \sinh x\,dx = \cosh x + C, \quad \int \cosh x\,dx = \sinh x + C$

---

### דוגמה 2.2
* **מקור בספר:** עמ' 117 (PDF עמ' 119)
אינטגרלים של חזקות ממשיות לפי הנוסחה $\int x^\alpha\,dx = \frac{x^{\alpha+1}}{\alpha+1} + C$:
- $\int \frac{1}{x^4}\,dx = \int x^{-4}\,dx = \frac{x^{-3}}{-3} + C = -\frac{1}{3x^3} + C$
- $\int \sqrt{x}\,dx = \int x^{1/2}\,dx = \frac{x^{3/2}}{3/2} + C = \frac{2}{3}x\sqrt{x} + C$
- $\int \frac{1}{\sqrt[3]{x}}\,dx = \int x^{-1/3}\,dx = \frac{x^{2/3}}{2/3} + C = \frac{3}{2}x^{2/3} + C$

---

### דוגמה 2.3
* **מקור בספר:** עמ' 118 (PDF עמ' 120)
אינטגרלים המפושטים באמצעות זהויות אלגבריות וטריגונומטריות מיידיות:
- $\int \tan^2 x\,dx = \int \left(\frac{1}{\cos^2 x} - 1\right)dx = \tan x - x + C$
- $\int \frac{x^2}{1+x^2}\,dx = \int \left(1 - \frac{1}{1+x^2}\right)dx = x - \arctan x + C$

## 2.3 שיטות בסיסיות

### 2.3.1 אינטגרציה בחלקים

#### משפט 2.6 (אינטגרציה בחלקים)
* **מקור בספר:** עמ' 125 (PDF עמ' 127; נספח עמ' 257)
אם הפונקציות $u$ ו-$v$ גזירות ובעלות נגזרות רציפות בקטע $I$, אז בקטע זה מתקיים:
$$\int u(x)v'(x)\,dx = u(x)v(x) - \int u'(x)v(x)\,dx$$
ובכתיב מקוצר של דיפרנציאלים ($du = u'dx, dv = v'dx$):
$$\int u\,dv = uv - \int v\,du$$

---

#### דוגמה 2.8
* **מקור בספר:** עמ' 127 (PDF עמ' 129)
חישוב $\int x e^x\,dx$:
בוחרים $u(x) = x \implies u'(x) = 1$, ו-$v'(x) = e^x \implies v(x) = e^x$.
$$\int x e^x\,dx = x e^x - \int 1 \cdot e^x\,dx = x e^x - e^x + C = (x-1)e^x + C$$

---

#### דוגמה 2.9
* **מקור בספר:** עמ' 128 (PDF עמ' 130)
חישוב $\int x\sin x\,dx$:
בוחרים $u(x) = x \implies u'(x) = 1$, ו-$v'(x) = \sin x \implies v(x) = -\cos x$.
$$\int x\sin x\,dx = -x\cos x - \int (-\cos x)\,dx = -x\cos x + \sin x + C$$

---

#### דוגמה 2.10
* **מקור בספר:** עמ' 129 (PDF עמ' 131)
חישוב $\int \ln x\,dx$:
רושמים $\int 1 \cdot \ln x\,dx$. בוחרים $u(x) = \ln x \implies u'(x) = \frac{1}{x}$, ו-$v'(x) = 1 \implies v(x) = x$.
$$\int \ln x\,dx = x\ln x - \int x \cdot \frac{1}{x}\,dx = x\ln x - \int 1\,dx = x\ln x - x + C$$

---

#### דוגמה 2.11
* **מקור בספר:** עמ' 130 (PDF עמ' 132)
חישוב $\int \arctan x\,dx$:
רושמים $\int 1 \cdot \arctan x\,dx$. בוחרים $u(x) = \arctan x \implies u'(x) = \frac{1}{1+x^2}$, ו-$v'(x) = 1 \implies v(x) = x$.
$$\int \arctan x\,dx = x\arctan x - \int \frac{x}{1+x^2}\,dx = x\arctan x - \frac{1}{2}\ln(1+x^2) + C$$

---

#### דוגמה 2.12
* **מקור בספר:** עמ' 131 (PDF עמ' 133)
אינטגרציה בחלקים חוזרת ל-$\int x^2 e^x\,dx$:
בוחרים $u = x^2, v' = e^x \implies u' = 2x, v = e^x$.
$$\int x^2 e^x\,dx = x^2 e^x - 2\int x e^x\,dx$$
לפי דוגמה 2.8, $\int x e^x\,dx = (x-1)e^x$. לכן:
$$\int x^2 e^x\,dx = x^2 e^x - 2(x-1)e^x + C = (x^2 - 2x + 2)e^x + C$$

---

#### דוגמה 2.13
* **מקור בספר:** עמ' 134 (PDF עמ' 136)
חישוב אינטגרל מעגלי: $I = \int e^x\sin x\,dx$.
1. בוחרים $u = e^x, v' = \sin x \implies u' = e^x, v = -\cos x$:
   $$I = -e^x\cos x + \int e^x\cos x\,dx$$
2. שוב אינטגרציה בחלקים על $\int e^x\cos x\,dx$ עם $u = e^x, v' = \cos x \implies u' = e^x, v = \sin x$:
   $$\int e^x\cos x\,dx = e^x\sin x - \int e^x\sin x\,dx = e^x\sin x - I$$
3. מציבים חזרה:
   $$I = -e^x\cos x + e^x\sin x - I \implies 2I = e^x(\sin x - \cos x)$$
   $$I = \frac{e^x}{2}(\sin x - \cos x) + C$$

### 2.3.2 שיטת ההצבה (החלפת משתנים)

#### כלל ההצבה לאינטגרל בלתי-מסוים
* **מקור בספר:** עמ' 136 (PDF עמ' 138)

#### דוגמה 2.16
* **מקור בספר:** עמ' 138 (PDF עמ' 140)

$$\int 2x(x^2+1)^5\,dx = \int u^5\,du = \frac{u^6}{6} + C = \frac{(x^2+1)^6}{6} + C$$

#### דוגמה 2.17
* **מקור בספר:** עמ' 138 (PDF עמ' 140)

#### שאלה 16 (כלל הנגזרת הלוגריתמית)
* **מקור בספר:** עמ' 139 (PDF עמ' 141)
**נוסח השאלה:**
הוכיחו את כלל האינטגרציה עבור שבר שבו המונה הוא נגזרת המכנה:
$$\int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C$$
וחשבו בעזרתו את $\int \tan x\,dx$ ואת $\int \cot x\,dx$.

**תוצאה / מסקנה מוכחת:**
בהצבה $u = f(x) \implies du = f'(x)\,dx$, מקבלים $\int \frac{du}{u} = \ln|u| + C = \ln|f(x)| + C$.
- $\int \tan x\,dx = \int \frac{\sin x}{\cos x}\,dx = -\int \frac{-\sin x}{\cos x}\,dx = -\ln|\cos x| + C = \ln|\sec x| + C$
- $\int \cot x\,dx = \int \frac{\cos x}{\sin x}\,dx = \ln|\sin x| + C$

#### דוגמה 2.20

### 2.3.3 אינטגרציה של פונקציות רציונליות

#### משפט 2.7 (חילוק פולינומים עם שארית)
* **מקור בספר:** עמ' 150 (PDF עמ' 152; נספח עמ' 257)
בהינתן פולינומים ממשיים $P(x)$ ו-$Q(x)$ כאשר $Q(x) \ne 0$, קיימים פולינומים יחידים $S(x)$ (מנה) ו-$R(x)$ (שארית) כך ש:
$$P(x) = Q(x)S(x) + R(x) \quad \text{כאשר } \deg R < \deg Q \text{ או } R(x) \equiv 0$$
ולכן:
$$\frac{P(x)}{Q(x)} = S(x) + \frac{R(x)}{Q(x)}$$

#### משפט 2.8 (פירוק פולינום לגורמים אי-פריקים מעל $\mathbb{R}$)
* **מקור בספר:** עמ' 151 (PDF עמ' 153; נספח עמ' 257)
כל פולינום ממשי $Q(x)$ עם מקדם מוביל 1 ניתן להצגה יחידה כמכפלה של גורמים ליניאריים וריבועיים אי-פריקים (בעלי דיסקרימיננטה שלילית $p_j^2 - 4q_j < 0$):
$$Q(x) = (x-a_1)^{m_1} \cdots (x-a_k)^{m_k} (x^2 + p_1 x + q_1)^{n_1} \cdots (x^2 + p_r x + q_r)^{n_r}$$

#### משפט 2.9 (פירוק לשברים חלקיים של פונקציה רציונלית אמיתית)
* **מקור בספר:** עמ' 152 (PDF עמ' 154; נספח עמ' 258)
תהי $\frac{R(x)}{Q(x)}$ פונקציה רציונלית אמיתית ($\deg R < \deg Q$) עם מקדם מוביל 1 של $Q(x)$. אזי קיימת הצגה יחידה של $\frac{R(x)}{Q(x)}$ כסכום של שברים חלקיים פשוטים:
1. לכל גורם ליניארי $(x-a)^m$ במכנה, מתאים סכום של $m$ שברים:
   $$\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \dots + \frac{A_m}{(x-a)^m}$$
2. לכל גורם ריבועי אי-פריק $(x^2+px+q)^n$ במכנה, מתאים סכום של $n$ שברים:
   $$\frac{B_1 x + C_1}{x^2+px+q} + \frac{B_2 x + C_2}{(x^2+px+q)^2} + \dots + \frac{B_n x + C_n}{(x^2+px+q)^n}$$

#### ארבעת סוגי האינטגרלים היסודיים של שברים חלקיים
1. $\int \frac{A}{x-a}\,dx = A\ln|x-a| + C$
2. $\int \frac{A}{(x-a)^m}\,dx = -\frac{A}{(m-1)(x-a)^{m-1}} + C \quad (m > 1)$
3. $\int \frac{Bx+C}{x^2+px+q}\,dx = \frac{B}{2}\ln(x^2+px+q) + \frac{C - Bp/2}{\sqrt{q - p^2/4}}\arctan\left(\frac{x+p/2}{\sqrt{q-p^2/4}}\right) + C$
4. $\int \frac{Bx+C}{(x^2+px+q)^n}\,dx$ מחושב על ידי פיצול לנגזרת המכנה ושימוש בנוסחת הנסיגה של שאלה 15.

> **מסקנה מוחלטת:** לכל פונקציה רציונלית קיימת פונקציה קדומה שהיא **אלמנטרית** (מורכבת מפולינומים, לוגריתמים וקשת-טנגנס)!

### 2.3.4 הצבות טריגונומטריות והצבות ויירשטראס

#### הצבות טריגונומטריות סטנדרטיות
1. עבור ביטוי מהצורה $\sqrt{a^2 - x^2}$: מציבים $x = a\sin\theta$ ($dx = a\cos\theta\,d\theta$).
2. עבור ביטוי מהצורה $\sqrt{a^2 + x^2}$: מציבים $x = a\tan\theta$ ($dx = a\sec^2\theta\,d\theta$).
3. עבור ביטוי מהצורה $\sqrt{x^2 - a^2}$: מציבים $x = a\sec\theta$ ($dx = a\sec\theta\tan\theta\,d\theta$).

#### הצבת טנגנס חצי הזווית (הצבת ויירשטראס האוניברסלית)
* **מקור בספר:** עמ' 161 (PDF עמ' 163)
עבור אינטגרל של פונקציה רציונלית של $\sin x$ ו-$\cos x$, מציבים $t = \tan(x/2)$ (עבור $-\pi < x < \pi$). מתקיים:
$$\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2\,dt}{1+t^2}$$
הצבה זו מתמירה כל אינטגרל טריגונומטרי לאינטגרל של פונקציה רציונלית של $t$.

### משפט 2.11 (כלל ההצבה לאינטגרלים מסוימים)

### שאלה 43 (משפט הסימטריה לפונקציות זוגיות ואי-זוגיות)
* **מקור בספר:** עמ' 173 (PDF עמ' 175)
**נוסח השאלה:**
תהי $f$ פונקציה רציפה בקטע הסימטרי $[-a, a]$ ($a > 0$).
א. הוכיחו כי אם $f$ אי-זוגית ($f(-x) = -f(x)$ לכל $x$), אז:
   $$\int_{-a}^a f(x)\,dx = 0$$
ב. הוכיחו כי אם $f$ זוגית ($f(-x) = f(x)$ לכל $x$), אז:
   $$\int_{-a}^a f(x)\,dx = 2\int_0^a f(x)\,dx$$

**תוצאה / מסקנה מוכחת:**
מפצלים את האינטגרל לפי אדיטיביות לקטעים:
$$\int_{-a}^a f(x)\,dx = \int_{-a}^0 f(x)\,dx + \int_0^a f(x)\,dx$$
באינטגרל הראשון מבצעים את ההצבה $x = -t \implies dx = -dt$ ($x=-a \implies t=a, x=0 \implies t=0$):
$$\int_{-a}^0 f(x)\,dx = \int_a^0 f(-t)(-dt) = \int_0^a f(-t)\,dt$$
1. **אם $f$ אי-זוגית:** $f(-t) = -f(t)$, ולכן $\int_{-a}^0 f(x)\,dx = -\int_0^a f(t)\,dt$. 
   חיבור שני החלקים נותן:
   $$\int_{-a}^a f(x)\,dx = -\int_0^a f(t)\,dt + \int_0^a f(t)\,dt = 0$$
2. **אם $f$ זוגית:** $f(-t) = f(t)$, ולכן $\int_{-a}^0 f(x)\,dx = \int_0^a f(t)\,dt$.
   חיבור שני החלקים נותן:
   $$\int_{-a}^a f(x)\,dx = \int_0^a f(t)\,dt + \int_0^a f(t)\,dt = 2\int_0^a f(x)\,dx$$
